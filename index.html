PANDUAN

Cara menggunakan

Panduan singkat ChordSasy.

Menulis chord

Ketuk kotak ketukan pada birama untuk membuka editor. Pilih angka akar, kualitas chord, bass inversion, atau simbol khusus. Tekan Simpan.

Mode Angka

Menampilkan derajat nada relatif terhadap Do. Contoh Do=G: G menjadi 1, Am menjadi 2m, C menjadi 4, D menjadi 5.

Mode Simple

Menampilkan angka akar saja. Kamu dapat mengisi chord khusus untuk satu ketukan tanpa mengubah notasi utama.

Mode Chord

Mengubah angka kembali menjadi nama chord berdasarkan nada dasar aktif.

Data dan privasi

Data disimpan di browser perangkat ini. Tidak ada akun, server, API key, atau sinkronisasi cloud. Gunakan Backup secara berkala.
